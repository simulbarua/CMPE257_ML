# Baby ADRec: authors' embeddings and warm-up

New runs use the pinned original authors' Baby embedding checkpoint for both five-epoch and zero-epoch warm-up, with downstream seeds 42–46. Only item_embedding.weight initializes ADRec; the backbone starts fresh. No embedding pretraining is repeated. All full configurations match their corresponding historical project conditions, including 32 diffusion steps and validation-based checkpoint selection.

Four conditions are compared: authors/project embeddings, each with warmup_epochs=5/0. Historical project scores are reused, not re-evaluated or retrained. accuracy_runs.csv and accuracy_summary.csv use only seeds with both new conditions complete, ensuring identical seed coverage for all four groups. completed_author_runs.csv includes every completed new run. completion.json records coverage. paired_differences.csv reports authors minus project for each warm-up setting, and warmup0 minus warmup5 within each embedding source, in percentage points. Mean and sample standard deviation are computed separately by condition; a single completed seed has no standard deviation.

All new runs share one fixed released authors' checkpoint, whose pretraining seed is unrecorded. Historical project runs used independently pretrained per-seed embeddings. Their standard deviations therefore include different sources of randomness. This comparison measures the effect of substituting this particular released checkpoint under our trainer, not all possible differences in pretraining procedures. Runtime changes and the documented trainer differences remain relevant. Our warm-up strictly freezes embeddings, unlike possible weight-decay updates through the released optimizer. Source compatibility checks and accepted migrations are recorded separately. This is not an exact replication of the paper's training pipeline, and the release does not establish that this file is the checkpoint used for every reported paper run.

paper_reference.csv contains published Baby point estimates from Table 4, https://arxiv.org/html/2505.19544v1#S4.SS4. They are references, not measurements from this notebook; no paper per-seed scores or standard deviations are invented. No inference-speed benchmark is performed. Weights are stored separately from result metadata. Checkpoint provenance is in author_checkpoint.json.
