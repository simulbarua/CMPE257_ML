- **Dataset checksum / split definition:** `dataset.pkl` SHA-256 `bf8f3485f9e36763e07f0234e0ddb479cb023358797615388a36f0d7238cea99`. 11,761 users, 4,731 items; train 69,301 / val 11,761 / test 11,761 interactions. Released per-user holdout split (see `evaluation/PROTOCOL.md`).
- **Config file / random seed:** `configs/kaggle.json` via `make_config('gru4rec', 'full')`; per-seed configs saved as `gru4rec_seed{42..46}_config.json`. Seeds 42, 43, 44, 45, 46. Key settings: hidden size 128, 1 GRU layer, dropout 0.3, max length 50, batch size 512, learning rate 0.001, weight decay 1e-5, up to 500 epochs, evaluation every 5 epochs, patience 4.
- **Python and package versions:** Python 3.13.16, PyTorch 2.11.0+cu130, CUDA 13.0. Full list in `requirements-lock.txt`.
- **Hardware / accelerator:** Kaggle notebook, NVIDIA Tesla T4 (single GPU used).
- **Training command or notebook:** Kaggle notebook `GRURec` (imported from `notebooks/anusha_gru4rec_kaggle.ipynb` in the bundle). Seed 42: `RUN_MODE='full'`, Kaggle Version 2. Seeds 43–46: loop cell in the same notebook calling `train(cfg, DATASET_PATH, WORK_ROOT/'runs'/f'mahalakshmi_gru4rec_full_seed{s}'/'gru4rec', finalize=True)` with `cfg['seed'] = s`.
- **Evaluation command:** Built into `train(..., finalize=True)`: shared evaluator, protocol `adrec_upstream`, run once on the test split after training.
- **Training stages completed / pretrained weight source:** Single training stage, trained from scratch. No pretrained weights.
- **Validation selection rule:** Validation every 5 epochs; the checkpoint is kept when any validation metric improves. Early stop after 4 validations with no improvement. Best epochs: 10, 5, 10, 15, 10 (seeds 42–46).
- **Metrics and candidate-item rules:** HR@5/10/20 and NDCG@5/10/20, reported in percent. Candidate rules follow `evaluation/PROTOCOL.md` (all item columns 0..4731, no filtering of padding or previously seen items, evaluation batch size 512).
- **Results / variability:** Mean ± sample std over 5 seeds: HR@10 1.8804 ± 0.1574, NDCG@10 0.9265 ± 0.0600, HR@20 3.4234 ± 0.1495, NDCG@20 1.3139 ± 0.0499. Per-seed values in `gru4rec_baby_runs.csv`; summary in `gru4rec_baby_summary.csv`.
- **Training and inference timing methodology:** Not measured per epoch. Kaggle Version 2 (seed 42, including package install) ran in 2 min 8 s on a T4. No separate inference timing.
- **Checkpoint location and checksum:** Seed 42 `best.pt` / `latest.pt` are in the output of Kaggle notebook `GRURec`, Version 2 (private). Seeds 43–46 ran in an interactive Kaggle session; their weights were not saved after the session ended. Results, configs and histories are kept here. Checksums not recorded.
- **Known limitations / deviations from paper:** This is a RecBole-derived GRU4Rec with cross-entropy loss on the final target of each history. It is not verified to match the GRU4Rec implementation or settings used in the ADRec paper, so the scores are not a direct reproduction of the paper's GRU4Rec numbers. Paper Table 2 GRU4Rec values have not been added to the summary yet.
