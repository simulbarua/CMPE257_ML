# Shared project code

This directory contains dataset loading and sequence preparation, model adapters, evaluation functions, training and inference code, and reproducibility utilities. The Kaggle notebooks use these shared modules for ADRec, GRU4Rec, and SASRec+.

Original model sources and licenses are retained in `third_party/`. See the [shared-code guide](../docs/SHARED_CODE_GUIDE.md) for module responsibilities and usage.
